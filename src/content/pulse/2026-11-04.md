## 重点论文与技术动态

### 1. PyRUA-DataFarm: LLM Agent as a Cost-Efficient Teleoperator for Real-Ready Robot Data

- **来源**：[arXiv](http://arxiv.org/abs/2611.05320v1)
- **日期**：2026-11-03
- **作者/机构**：Kewei Zhang, Juncheng Ma, Guodong Lv, Duomin Wang, Feixiang Ruan, Ruiyang Si
- **主题标签**：`RAG`, `arXiv`
- **推荐等级**：高
- **分类**：cs.RO, cs.AI

#### 一句话结论
PyRUA-DataFarm 利用 LLM 编码智能体在仿真中自动重建任务并结合视频渲染生成数据，能以更低成本替代人工遥操作，且策略在真实机器人上泛化性更强。

#### 核心内容
- **全流程自动生成**：智能体仅需单次真实校准演示即可在仿真中编写场景、控制器和判据，生成动作对齐的多视角真实级视频数据。
- **性能与泛化兼备**：在5个真实任务中，合成数据训练的策略成功率（93/100）匹配遥操作（84/100），在光照及桌布变动下鲁棒性大幅领先（87 vs 46）。
- **极具成本效益**：无需机器人和人工，单任务适配仅约\$26，单条数据生成约\$0.80，1小时三视角数据成本（\$107）低于人工遥操作费用。

#### 方法与数据
- 采用代码智能体在仿真中提供精确动作，结合视频模型多视角一致渲染，并经由独立裁判审核后直接用于策略训练。
- 数据集评估覆盖 5 个真实机器人任务，并在 100 次试验中对比了常规与未知扰动环境。

#### 价值判断
- **值得关注**：纯合成数据训练的策略在光照和背景扰动下的抗干扰能力远超遥操作数据。
- **可复用点**：智能体编写仿真专家+视频模型跨模态渲染“即用型”数据的全自动数据工场管线。
- **局限/待核查**：摘要未展开复杂交互动力学下视频渲染的物理一致性，以及更多自由度复杂任务的适用边界。

<details>
<summary>摘要</summary>
Teleoperation remains the default way to collect robot demonstrations, but every episode costs robot and operator time, and every new task starts from scratch. We ask whether a coding agent can take over the teleoperator's job. In our DataFarm, the agent receives a data request and one calibration episode of the robot in the target scene and rebuilds the task in simulation: it writes the scene, an expert controller, and a success judge. The simulator supplies exact actions, and a video model conditioned on real images renders each rollout as photographic video, generating all camera views together consistently. The output is real-ready data: synchronized camera views labelled with the robot's actions, on which a policy can be trained directly and deployed on the real robot. Independent judges certify the expert and every rendered episode before admission. On five real-robot tasks, policies trained only on farm data match policies trained on as many teleoperated episodes (93 vs. 84 successes in 100 trials), and under an unseen tablecloth and coloured light they keep 87 successes where the teleoperation-trained policies fall to 46. Adapting a task is fully automatic and costs \$21 of API usage on average, paid once per task, plus \$5 for a render contract; every further episode costs \$0.80 on average for simulation, rendering, and review, with no robot or operator. One hour of three-view data for a task costs \$107 on average, these costs included, slightly below a quote of \$117 for teleoperation in China and below \$290 in labour alone in North America.

### 2. ToolSched: Resource-Efficient Tool Scheduling for Shared-Host LLM Agents

- **来源**：[arXiv](http://arxiv.org/abs/2611.05269v1)
- **日期**：2026-11-03
- **作者/机构**：Shucheng Zou, Yuhao Gu, Long Chen, Zhongchun Zheng, BinZe Xie, Xianwei Zhang
- **主题标签**：`MCP`, `arXiv`
- **推荐等级**：高
- **分类**：cs.OS

#### 一句话结论
ToolSched 是面向受限本地共享主机的 Shell MCP 调度系统，通过结合 Agent 资源预估与实时状态错峰执行命令，显著缓解并发争用并提升吞吐量。

#### 核心内容
- **痛点与契机**：本地共享主机 CPU、内存及 I/O 受限，并发 Agent 易突发争用导致 OOM；但 Agent 对 Shell 延迟不敏感，存在充裕的调度空间。
- **调度机制**：作为服务多 Agent 的 Shell MCP 服务器，ToolSched 将资源模型嵌入接口，结合 Agent 的需求预估提示与主机实时状态动态错峰调度命令。
- **容错设计**：内置预测修正和基于检查点的恢复机制，以减轻资源估计偏差并解决运行时的资源错误。

#### 方法与数据
- 在 Terminal Bench 上的评测表明，ToolSched 相比未调度的执行方式，资源利用率提升了 148.4%，端到端命令吞吐量提升了 29.4%。

#### 价值判断
- **值得关注**：针对本地轻量级多 Agent 落地场景，开创性地将传统 OS 资源调度思想与 MCP 协议深度融合。
- **可复用点**：Agent 端“预估提示 + 接口嵌入”与服务端“错峰调度 + 检查点恢复”的软硬协同架构。
- **局限/待核查**：前置资源预估对 Agent 模型能力存在依赖；检查点机制带来的额外 I/O 开销与通用性在摘要中未明确。

<details>
<summary>摘要</summary>
Local LLM agents often work on shared hosts. Unlike multi-tenant cloud clusters, these hosts often have tightly bounded memory, CPU, and I/O resources. Concurrent agents frequently suffer from resource contention, leading to failures such as OOM and reduced resource efficiency. Considering that agents' resource demands are bursty and shell command delay is imperceptible to agents, there is a huge scheduling opportunity to arrange when and in what order commands are actually executed. Thus, we present ToolSched, a Shell MCP Server for shared local hosts that serves multiple agents and schedules their operations. ToolSched embeds a resource model into the MCP interface: agents estimate resource demands along with command requests. These hints, together with real-time host resource conditions, determine when commands are actually executed. Internally, ToolSched applies a scheduling algorithm to stagger commands, reducing contention and improving resource utilization. Prediction correction and checkpoint-based recovery mitigate estimation bias and resource errors. Our evaluation on Terminal Bench shows that, compared with unscheduled execution, ToolSched improves resource utilization by 148.4% and end-to-end command throughput by 29.4%, demonstrating its effectiveness and practicality.

</details>
