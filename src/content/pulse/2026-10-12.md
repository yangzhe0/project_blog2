### 1. RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics

- **来源**：[arXiv](http://arxiv.org/abs/2610.13889v1)
- **日期**：2026-10-09
- **作者/机构**：Weiliang Chen, Song Liao
- **主题标签**：`AI-Agent`, `arXiv`
- **推荐等级**：高
- **分类**：cs.AI, cs.IR

#### 一句话结论
本文提出结合语义匹配与动态可靠性适应的AI智能体工具检索框架RATED，无需重新训练模型即可有效应对运行时外部工具失效的问题。

#### 核心内容
- 针对现有方法只优化语义相关性而忽视工具执行期可用性的痛点，提出RATED检索框架。
- 构建并开源了包含5,172个真实工具和超21万查询-工具对的评测基准EcoAgent。
- 相比ToolLLM检索器，RATED相对MRR提升52.2%；在30%故障率的严重API中断下，将错误选择率从86.2%降至2.9%，且额外延迟低于1毫秒。

#### 方法与数据
- 采用经对比微调的冻结双编码器进行语义匹配，并结合轻量级上下文赌博机（contextual bandit）模块，基于实时执行反馈动态重排候选工具。

#### 价值判断
- **值得关注**：能快速适应运行时工具故障，大幅降低错误选择率，且推理延迟开销极低（<1ms）。
- **可复用点**：“冻结双编码器+上下文赌博机”的免重训动态重排机制，以及开源的EcoAgent代码与数据集。
- **局限/待核查**：摘要未明确上下文赌博机的具体算法细节及双编码器的基础模型选型。

<details>
<summary>摘要</summary>
As AI agents increasingly rely on external tools, accurate retrieval is essential for reliable behavior. Existing methods optimize semantic relevance but largely ignore tool availability during execution. To address this gap, we propose RATED (Reliability-Aware Tool Retrieval via Execution Dynamics), a retrieval framework that combines robust semantic matching with dynamic reliability adaptation. RATED employs a frozen dual-encoder with contrastive fine-tuning for semantic matching, and a lightweight contextual bandit module that re-ranks candidates based on real-time execution feedback. This design enables rapid adaptation to runtime tool failures without expensive model retraining. We introduce EcoAgent, a benchmark of 5,172 real-world tools and over 210,000 query-tool pairs for offline retrieval and dynamic reliability evaluation. Experimental results demonstrate that RATED achieves a 52.2% relative MRR improvement over the ToolLLM API retriever on real-world queries, and reduces fault selection rate from 86.2% to 2.9% under severe API outage scenarios with a 30% failure rate, while incurring negligible latency overhead of less than 1 ms over encode-only inference. The code and dataset are available at https://github.com/Elliotes/EcoAgent.

</details>

### 2. BT-Agent: Deploying Onboard Robot Agents with Behavior Trees and Multi-Fidelity Evaluation

- **来源**：[arXiv](http://arxiv.org/abs/2610.13862v1)
- **日期**：2026-10-09
- **作者/机构**：Fabio Hübel, Adam Lilja, Yue Yin, Siming He, Claire Tomlin, Shankar Sastry
- **主题标签**：`AI-Agent`, `arXiv`
- **推荐等级**：高
- **分类**：cs.RO

#### 一句话结论
本文提出结合LLM任务决策与预定义行为树（BT）技能的机载架构BT-Agent，在算力和内存受限的移动机器人上实现了任务推理与响应执行。

#### 核心内容
- BT技能强制执行条件并返回结构化失败反馈；本地检查无需等待模型决策即可中止导航，同时保持代理活跃以进行重试或报告约束。
- 在四足机器人上搭载9B模型，成功演示了跨5个任务类别的完全机载运行。
- 相比最强的Act/ReAct基线，该架构在4B和9B模型上的最大成功率提升分别约为10和5个百分点。

#### 方法与数据
- 构建含161项任务的多保真度基准：全量任务经文本评测（提升10.9倍吞吐量），其中39项经Habitat仿真评测（揭示感知与运动失败对结果的影响）。

#### 价值判断
- **值得关注**：利用端侧小模型（4B/9B）结合行为树，在受限机载算力下兼顾了推理与本地实时安全控制。
- **可复用点**：消融实验证实最有效的“结构化工具调用”与“信息丰富的失败反馈”组件，以及多保真度评测方法。
- **局限/待核查**：仿真评测仅覆盖39项任务，且真机5类任务的具体内容与硬件细节摘要未明确。

<details>
<summary>摘要</summary>
Deploying language-model agents onboard mobile robots requires task reasoning and responsive execution within limited compute and memory. We propose BT-Agent, an onboard architecture combining LLM-driven task decisions with predefined behavior-tree (BT) skills. These skills enforce execution conditions and return structured failure feedback. We demonstrate fully onboard operation with a 9B model on a quadruped across five task categories. Intervention tests show that local checks stop ongoing navigation without waiting for another model decision, while the agent remains active to retry or report constraints. To compare agent designs efficiently, we introduce a 161-task multi-fidelity benchmark, evaluated in text on all tasks and in Habitat on 39. Text supports 10.9$\times$ higher evaluation throughput, while simulation reveals how perception and motion failures change task outcomes. BT-Agent's largest success gains over the strongest Act/ReAct baseline occur at 4B and 9B: approximately 10 and 5 percentage points. Ablations identify structured tool calls and informative failure feedback as the most useful components.

</details>
