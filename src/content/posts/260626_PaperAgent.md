> 在严肃的天文与天体测量科研场景中，通用的问答模型往往无法直接触达课题组专属的学术论文库，且极易出现术语幻觉、推理割裂与无法严密溯源的问题。`PaperAgent` 是一个面向**天体测量与学术论文库的深度研读智能体**，将专业文献解析为结构化知识表征，支持跨文献比对与确定性过滤，且每一条学术推论皆可精确回溯到原文切片。

---

## 一、核心定位与技术栈演进

### 1. 核心解决的学术研读痛点
- **拒绝黑盒问答，严格文件级溯源**：每一个回答均提供对应的论文文件名、章节层级路径及支撑结论的原切片引用。
- **确定性索引与学术长思维链深度结合**：作者成果清单、特定天体（如木星/土星天然卫星）数据源走倒排索引秒级返回；跨时代星表修正原理与复杂误差推导进入深层思维链（Reasoning Trace）逐步推演。
- **科研级全端响应式研读**：重构 Streamlit 默认布局，深度定制移动端（390px 视口）适配样式，实现桌面端与移动端一致的流式深度交互。

### 2. 现代技术栈选型

```text
前端界面: Streamlit (深度定制响应式 CSS，适配桌面端与 390px 移动视口)
文档解析: MinerU (高保真学术 PDF 布局、公式与层级树解析)
切片策略: 1600 字符层次感知切片 (保留 H1/H2 路径与 180 字符重叠)
文本嵌入: BGE-M3 (高维度语义表征，兼顾密集向量与稀疏关键词权重)
检索体系: FAISS 稠密向量索引 + BM25 稀疏检索 (RRF 倒数排名融合)
推理内核: 标准通用兼容接口，长上下文与长思维链学术推理内核 (Flash / Thinking / Pro)
调度编排: 元数据倒排过滤 + 多路路由分流调度引擎 + 来源严格回溯机制
```

### 3. 多档学术推理策略
系统根据科研研读场景提供灵活的内核档位：
- **Flash 模式**：轻量极速响应，专用于术语定义快速查询、单篇文献概要提炼及元数据索引问答。
- **Thinking 模式**：激活深层思维链（Reasoning Trace），针对复杂星表系统差改正机制、多体轨道摄动建模等长逻辑链条进行逐步推导与验证。
- **Pro 模式**：高上下文综合研读模式，面向跨年代历史星表修正范式对比与长篇学术综述生成。

## 三、核心技术突破

### 1. 1600 字符层次感知切片设计
在早期原型中，过小的切片（如 500 字符）常将完整的数学推导公式或观测条件拆成断片，导致检索召回后模型“只见树木不见森林”。

PaperAgent 采用了 **1600 字符层次感知切片**：
- **语义完整性**：1600 字符足以完整包裹一个二级标题下的方法论推导或数据筛选准则。
- **层级元数据挂载**：在每个切片切分时，将所属的 `Section > Subsection` 标题路径作为前缀元数据固化，即使切片内部没有直接提到上下文主题，检索阶段也能准确定位其在整篇论文中的语义位置。
- **180 字符滑动重叠**：平滑边缘语义，杜绝因截断导致的推导逻辑丢失。

### 2. 确定性路由与双向平衡对比
学术研读中充斥着对比类问题（例如：“对比 Gaia DR2 与 Gaia DR3 在历史星表自行系统差改正中的作用”）。常规 RAG 往往直接按综合相似度检索，导致篇幅较长的一方严重挤占召回窗口。

PaperAgent 实现了**双向检索平衡机制**：
1. 实体识别器抽取出对比双方（`Gaia DR2` 与 `Gaia DR3`）。
2. 构建隔离并行的双向检索流，各自召回 Top-K 片段后进行等权重交叉融合。
3. 确保学术推理内核在生成对比矩阵时，两侧的数据支撑同等完备。

### 3. Streamlit 移动端（390px 视口）响应式重构
Streamlit 默认在移动端存在侧边栏遮挡、代码块水平滚动失效、流式文字生成时页面抖动等痛点。为满足移动科研研读需求，系统在前端进行了专门的 CSS 注入与布局改造：
- **自适应视口断点**：在 `@media (max-width: 768px)` 下自动调整容器 Padding、侧边栏折叠抽屉及字体比例。
- **流式思维链（Reasoning）组件**：定制可折叠的原生折叠框组件，将模型的推理过程与正式结论解耦渲染，保证手机屏幕上阅读主干流畅清爽。
- **无缝长文档排版**：优化表格、公式及代码块在狭窄视口下的自适应折行与横向惯性滚动。

## 四、服务启动与流水线更新

### 1. 运行 Web 研读端
```bash
# 启动 Streamlit 响应式研读界面
streamlit run app.py \
  --server.address 0.0.0.0 \
  --server.port 8000 \
  --server.headless true
```

### 2. 论文库增量解析与索引流水线
当新增天体测量批次文献（PDF）时，执行结构化处理流水线：
```bash
# 1. 将新 PDF 放入数据目录
# 2. 执行 MinerU 结构化解析
python scripts/parse_papers.py --input-dir data/papers/ --output-dir data/parsed/

# 3. 运行 1600 字符层次切片并重建向量与倒排索引
python scripts/build_hybrid_index.py --parsed-dir data/parsed/
```
